MoneyFlow

Everyday spending.
Longer-term goals.

A Flutter app for manually tracking spending, account balances, and savings goals. Financial records stay locally in SQLite; the app does not connect to banks or move real money.

FlutterDartSQLite
Behind the project +

Record income, expenses, withdrawals, and transfers; plan savings goals; review spending summaries; set budgets and recurring rules; export or restore JSON backups. Recurring rules run when the app starts or when Run Due is used.

Available on GitHub only. Not yet released on any app store, including Google Play or the Apple App Store.

MUSIC & AUDIOWORKING MVP

MelodyToTab

Hum an idea.
Find it on the guitar.

A local Windows app that turns short, unaccompanied hummed or sung melodies into editable notes, guitar tablature, and suggested chord progressions.

C#.NET 10Windows FormsNAudio
Behind the project +

Record or import WAV audio, edit notes and fingerings, compare original and synthesized playback, save .mtab projects, and export PDF or melody-only MIDI. Clean single-voice recordings work best; key, rhythm, and chords are estimates to review.

Working MVP, as described in the repository. Source available on GitHub; no GitHub release was listed when checked on October 14, 2026.
